# AniZone v2.0.0 — website title first

CloudAnime v1.8.37 patch. Apply manifest.json and providers/anizone.js at repository root. Other provider entries are unchanged from v1.8.36. No YAML or file deletions.

Routing: use a confirmed cached website slug when available; otherwise reuse matching VUEO TMDB title metadata or fetch one TMDB detail. AniZone has no published TMDB-direct route, so unsupported requests are skipped. Search the website catalogue by title and native/alternative aliases, then accept a unique exact normalized title with season/type/year and episode-count checks. A sequel cannot silently use an unsuffixed first-season match. Special season zero uses mapping only. If titles are absent, unmatched or ambiguous, use verified ARM/AniZip episode mapping and exact catalogue aliases. No first-result, substring or guessed season-offset selection remains. The duplicated legacy anizone-v2 engine is removed; display formatting and runtime module compatibility remain.

An exact title/season with a multi-episode count can use the requested local episode number; the website episode snapshot must corroborate its slug and number. The next episode can reuse the successful website ID for five minutes without repeating metadata/search. Signed media URLs are not cached. Failed source discovery does not create a successful ID cache entry.

Returns the first server with a valid HLS manifest and published Japanese audio. Mixed manifests retain the website master URL with VUEO's existing vueo_hls_v1 Japanese-audio filter. Muxed streams without published audio renditions require explicit Japanese-only page audio evidence. Dub-only, unknown-audio and HTML media responses are rejected. English/Malay/Indonesian sidecars retain VTT/ASS/SubRip MIME; Dubtitle captions are excluded. Alternative server requests run only after the default source fails.

Validation: 22 controlled regression cases passed against the full provider, including real recorded catalogue/episode/HLS fixtures, correct 2024 Blue Box versus 2026 sequel, cache path, positive mapping fallback, wrong/ambiguous titles, movie/TV separation, special season and mismatched episode snapshots. Current website search, episode and HLS each returned HTTP 200 during inspection. A subsequent cold provider run selected the correct slug but episode fetching timed out. This is not a full live Android playback verification. Native app testing remains necessary.
